# legion-prettier-config

Prettier settings for repos that follow
[LEGION-STANDARDS](https://github.com/Kprince1101/legion-toolkit#readme):
single quotes, trailing commas everywhere, 80 columns.

```jsonc
// package.json
{ "prettier": "legion-prettier-config" }
```

Or, to extend it:

```jsonc
// .prettierrc.json
"legion-prettier-config"
```

Also available as `legion-toolkit/prettier` from the umbrella package.
